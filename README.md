A two-line explanation of rain for a 10-year-old: line 1 explains rain through a concrete, surprising analogy — the sky wringing out a giant grey sponge it soaked up from the sea — and line 2 honestly says what the analogy maps (clouds really do collect water and let it fall when the drops get too heavy) and what it leaves out (no sponge exists; vapour cools, gathers into droplets, and falls on its own). The program writes the text deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` in pure Python stdlib, no network.

## Run it

```sh
python3 main.py
```
